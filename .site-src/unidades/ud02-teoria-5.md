# 5. Markdown y webs de documentación

Una empresa también documenta procesos en formato web: normas internas, manuales breves, preguntas frecuentes, enlaces a plantillas o instrucciones para clientes.

Markdown permite escribir documentación sencilla con títulos, listas, tablas, enlaces e imágenes sin depender de un procesador de textos pesado. Después puede publicarse en una web estática o convertirse a otros formatos.

## Qué es Markdown

Markdown es una forma de escribir texto estructurado con marcas simples:

```md
# Título principal

## Apartado

- Elemento de lista
- Otro elemento

[Texto del enlace](https://ejemplo.com)
```

No sustituye a Writer o Word cuando necesitamos estilos complejos, combinación o documentos formales. Sirve para documentación rápida, clara y fácil de versionar.

## Web documental de empresa

En esta unidad la web no es marketing. Es una página sencilla para organizar documentación:

- Quiénes somos.
- Qué documentos usa la empresa.
- Normas de estilo.
- Formatos internos y de entrega.
- Enlaces a plantilla, manual, formulario o PDF.
- Protocolo de revisión y protección de datos.

El objetivo es que alguien nuevo pueda entrar y entender cómo trabaja documentalmente la empresa.

## Relación con el procesador de textos

Writer/Word y Markdown no compiten; se complementan.

| Necesidad | Herramienta adecuada |
| --- | --- |
| Informe formal con portada e índice | Writer o Word |
| Manual imprimible para cliente | Writer o Word y PDF |
| Guía interna breve y enlazada | Markdown/web |
| Registro de versiones y decisiones | Markdown o tabla en documento de empresa |
| Contrato revisado | Writer o Word con control de cambios |

## Buenas prácticas

- Títulos jerárquicos, sin saltar niveles.
- Párrafos breves.
- Enlaces con texto significativo.
- Tablas pequeñas y legibles.
- Imágenes optimizadas y con explicación.
- Sin datos personales reales.
- Archivos con nombres claros.

## Práctica guiada

1. Crear una página `index.md` de la empresa.
2. Añadir una sección de normas documentales.
3. Añadir una tabla de formatos.
4. Enlazar plantilla, manual y PDF final.
5. Insertar una imagen o captura sin datos personales.
6. Revisar en vista web.

!!! info "Lo importante"
    La web debe organizar el trabajo de la empresa. No se evalúan efectos visuales espectaculares, sino claridad, estructura, enlaces útiles y coherencia con la identidad documental creada en la unidad.
