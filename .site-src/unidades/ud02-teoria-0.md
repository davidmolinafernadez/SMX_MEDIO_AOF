# 0. Formato de carácter y párrafo

Un procesador de textos no es una máquina de escribir digital. En una máquina de escribir, cada línea se coloca manualmente. En Writer o Word, el documento debe construirse separando **contenido**, **estructura** y **presentación**.

Si el alumno alinea con espacios, crea páginas con muchos Enter o simula títulos solo con tamaño y negrita, el documento puede parecer correcto durante unos minutos, pero se romperá en cuanto cambie el texto, se abra en otra suite o se exporte a PDF.

## Carácter, párrafo y página

El **carácter** es cada letra, número o símbolo. Su formato afecta a fragmentos pequeños: negrita, cursiva, color, superíndice o idioma.

El **párrafo** termina al pulsar Enter. Su formato afecta al bloque completo: alineación, sangría, espacio antes y después, interlineado, bordes, numeración o viñetas.

La **página** define el espacio donde viven los párrafos: tamaño, orientación, márgenes, encabezado, pie, columnas y numeración. Cambiar la página no debería hacerse con espacios ni saltos vacíos, sino con estilos de página o saltos controlados.

## Formato directo y formato estructural

El formato directo es un cambio aplicado a mano sobre un texto concreto. Sirve para casos puntuales, pero no para diseñar documentos largos. Si cada título se formatea manualmente, cualquier cambio obliga a revisar todo el documento uno por uno.

El formato estructural usa estilos. Un estilo indica qué función tiene un elemento: título principal, subtítulo, cuerpo, cita, aviso, lista o nota. Después se decide cómo se ve. Esta separación permite actualizar todo el documento de forma coherente.

| Mala práctica | Problema | Solución profesional |
| --- | --- | --- |
| Centrar con espacios | Se descoloca al cambiar fuente o abrir en otra suite | Alineación de párrafo |
| Crear páginas con Enter | Cambia al añadir o quitar texto | Salto de página o estilo de página |
| Título con negrita manual | No aparece en el índice | Estilo `Título 1` o `Título 2` |
| Lista escrita con guiones | No se renumera ni se alinea bien | Lista automática o estilo de lista |
| Imagen pegada sin anclaje | Se mueve o tapa texto | Ancla, ajuste y pie de imagen |

## Caracteres no imprimibles

La primera herramienta de diagnóstico es activar los caracteres no imprimibles. Permiten ver espacios, tabuladores, saltos de párrafo y saltos de página.

En clase se utilizarán para reparar documentos con errores reales: líneas vacías, tabulaciones irregulares, espacios dobles, listas falsas y saltos manuales innecesarios. No se evalúa que el alumno memorice el botón, sino que sepa detectar cuándo un documento está construido de forma frágil.

## Configuración básica de página

Antes de escribir un documento serio hay que decidir:

1. Tamaño de papel, normalmente A4.
2. Orientación vertical u horizontal.
3. Márgenes suficientes para lectura, impresión y encuadernación.
4. Encabezado y pie si el documento lo necesita.
5. Numeración de página mediante campo automático.
6. Idioma del documento para corrector y división silábica.

Una vez tomada la decisión, se registra como norma de empresa para que no cada documento empiece desde cero.

## Demostración Writer/Word

El profesor abre un documento defectuoso y realiza esta secuencia:

1. Activar caracteres no imprimibles.
2. Eliminar espacios y Enter usados para maquetar.
3. Convertir títulos simulados en títulos reales.
4. Corregir sangrías, interlineado y espacio entre párrafos.
5. Insertar un salto de página correcto.
6. Añadir encabezado, pie y número de página.
7. Exportar a PDF y comparar con el editable.

La ruta de menús puede variar entre Writer y Word, pero el criterio profesional es el mismo.

## Práctica guiada

Recibirás un texto en bruto. Debes transformarlo en un documento breve de empresa:

1. Pega el texto sin formato.
2. Divide el contenido en título, subtítulos, párrafos, lista y aviso.
3. Elimina dobles espacios, tabulaciones innecesarias y líneas vacías.
4. Ajusta alineación, sangrías, espaciado e interlineado.
5. Inserta una segunda página mediante salto, no mediante Enter.
6. Añade encabezado, pie y numeración automática.
7. Exporta a PDF y comprueba que no aparecen páginas en blanco ni cortes extraños.

!!! warning "Errores frecuentes"
    Justificar textos muy estrechos, subrayar títulos, mezclar demasiadas tipografías, insertar capturas como sustituto de texto editable, dejar líneas vacías para separar secciones o no revisar el PDF final.

## Comprobación

Un documento está bien construido si al añadir un párrafo en mitad del texto todo se recoloca sin romper portada, listas, numeración ni saltos. Si un pequeño cambio obliga a recolocar todo manualmente, todavía no es un documento profesional.
