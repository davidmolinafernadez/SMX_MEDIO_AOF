# 0. Objetivo, guion y captura

Grabar antes de planificar produce vídeos largos. Un tutorial define audiencia, estado inicial, resultado y criterio de éxito.

## Guion

| Campo | Pregunta |
| --- | --- |
| Audiencia | ¿Qué sabe y qué necesita? |
| Tarea | ¿Una acción observable? |
| Inicio | ¿Archivo/cuenta preparada? |
| Éxito | ¿Cómo sabrá que terminó? |
| Riesgo | ¿Qué error o dato proteger? |

Storyboard: tiempo, imagen, acción/locución y criterio. La locución no lee literalmente todo lo visible.

## Captura con OBS

Se elige fuente de ventana/pantalla, resolución, audio y carpeta. Se desactivan notificaciones, usan datos ficticios, amplía interfaz y hace prueba de 20 segundos. El profesor muestra equivalencias con grabadores comerciales; el concepto es fuente, escena, nivel y archivo.

## Práctica guiada

Redacta un guion de 90 segundos, prepara escritorio, graba prueba, comprueba imagen/audio y registra un problema. No se graba la versión final hasta aprobar guion.

!!! warning "Privacidad"
    No aparecen correos reales, nombres, historial, marcadores, claves ni notificaciones. Si ocurre, se repite o se oculta correctamente en edición.
