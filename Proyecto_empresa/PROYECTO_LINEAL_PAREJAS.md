# Proyecto lineal de empresa en parejas

Documento maestro editable. La versión para el alumnado se publica en `.site-src/proyecto-empresa.md`.

## Organización

- Parejas estables de dos integrantes.
- Actividades técnicas: individuales y entregadas por separado en Aules.
- Hito `PROY-n`: una entrega común por pareja al final de cada unidad.
- Roles alternos: coordinación/producción y calidad/documentación.
- Defensa o modificación individual breve en todos los hitos.

## Entregas

| Código | Producto grupal | Contenido mínimo |
|---|---|---|
| PROY-0 | Fundación | Ficha, necesidad, servicios, roles, carpetas y pitch |
| PROY-1 | Puestos | Inventario de dos puestos, software, licencias, formatos, pruebas e incidencias |
| PROY-2 | Documentación | Plantilla, documentos comerciales, manual y guía de estilo |
| PROY-3 | Control | Presupuesto, inventario, indicadores, panel y pruebas |
| PROY-4 | Base de datos | Modelo, tablas, consultas, formulario, informe y aceptación |
| PROY-5 | Imagen | Identidad, campaña, exportaciones y prototipo 3D |
| PROY-6 | Multimedia | Guía, vídeo, subtítulos y prueba con usuario |
| PROY-7 | Presentación | Storyboard, patrón, evidencias y defensa comercial |
| PROY-8 | Cierre | Correo, agenda, reunión, dossier y enlace al portfolio anual |

Las horas del proyecto están integradas en la temporización de cada unidad y no se suman a las 224 horas oficiales.
