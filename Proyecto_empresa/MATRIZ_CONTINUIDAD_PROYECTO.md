# Matriz de continuidad del proyecto de empresa

## Principio de funcionamiento

El alumnado trabaja en parejas estables de dos integrantes. En cada unidad se sigue siempre el mismo ciclo:

1. Cada alumno realiza y entrega sus actividades `ACT-n.n` de forma individual.
2. La pareja abre la última versión de `EMPRESA_EquipoXX`.
3. Compara las dos soluciones individuales y registra coincidencias, diferencias y errores.
4. Adopta una decisión conjunta justificada; no pega simplemente ambos trabajos.
5. Incorpora el nuevo producto al proyecto existente.
6. Actualiza ficha de empresa, decisiones, versiones y contribuciones.
7. Entrega un solo `PROY-n` por pareja y realiza una defensa individual.

`ACT-1.1` queda congelada y no se modifica porque ya está en realización. Sus dos resultados se utilizan como entrada de PROY-1.

## Archivos permanentes de gestión

La carpeta `00_Gestion` acompaña a toda la empresa:

| Archivo | Actualización mínima en cada PROY |
|---|---|
| `FICHA_EMPRESA.pdf` | Versión, producto nuevo, servicio afectado y enlace |
| `REGISTRO_DECISIONES.md` | Alternativas comparadas, decisión, motivo y responsables |
| `CONTROL_VERSIONES.md` | Fecha, versión, archivos modificados y prueba realizada |
| `CONTRIBUCIONES.md` | Trabajo de cada integrante y revisión cruzada |
| `PENDIENTES.md` | Errores conocidos, deuda técnica y siguiente acción |

## Regla de evaluación

- Las actividades individuales acreditan los resultados y criterios de aprendizaje personales.
- El proyecto valora integración, coherencia, aplicación profesional, continuidad y colaboración.
- La defensa individual confirma que ambos comprenden el producto completo.
- Un proyecto excelente no compensa la ausencia de una evidencia individual obligatoria.
- La nota del producto común puede ajustarse individualmente cuando la defensa o el registro de contribuciones muestran dominios diferentes.

### Puntuación orientativa de cada hito

| Apartado | Puntos |
|---|---:|
| Producto técnico y pruebas de la unidad | 4,0 |
| Continuidad con los productos anteriores | 2,0 |
| Comparación e integración de las dos soluciones individuales | 1,5 |
| Documentación, orden y accesibilidad | 1,0 |
| Registro de versiones y contribuciones | 0,5 |
| Defensa individual | 1,0 |

## Comprobación rápida del profesorado

Antes de aceptar un hito deben poder responderse cinco preguntas:

1. ¿Es la misma empresa que en el hito anterior?
2. ¿Se identifican las actividades individuales utilizadas?
3. ¿La pareja explica qué alternativa eligió y por qué?
4. ¿El producto nuevo reutiliza realmente archivos o datos anteriores?
5. ¿Queda preparado el material que necesitará el siguiente PROY?
