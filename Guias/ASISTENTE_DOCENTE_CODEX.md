# Uso del asistente docente en Codex

El archivo `AGENTS.md` de la raíz configura las instrucciones persistentes de este proyecto para trabajar como asistente del profesor de AOF. Abre los próximos chats de Codex dentro de este mismo proyecto para utilizar ese contexto.

## Ejemplos de peticiones

- «Prepara la siguiente sesión de UD02 a partir del seguimiento de los grupos A y B. Incluye demostración y práctica guiada».
- «Crea una práctica de hojas de cálculo vinculada a la empresa simulada, con enunciado, rúbrica y solución privada».
- «Revisa estas entregas con la rúbrica de la actividad y propón una calificación justificada para cada una».
- «Comprueba la cobertura de RA y CA de esta unidad y señala las evidencias que faltan».
- «Adapta esta actividad a una sesión de 55 minutos con refuerzo y ampliación».
- «Actualiza la versión web de este material y comprueba sus enlaces».

Cuanto más concreta sea la petición, mejor: indica unidad, actividad, grupo, duración y formato cuando sean relevantes. El asistente consultará primero los materiales del proyecto.

Las propuestas de notas requieren revisión docente. El archivo de instrucciones no crea un servicio que trabaje en segundo plano ni programa ejecuciones automáticas.
