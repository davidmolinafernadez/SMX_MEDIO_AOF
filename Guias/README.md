# Guías docentes

Esta carpeta reúne documentación transversal para impartir AOF: instrucciones de uso del repositorio, dinámica de clase, demostraciones de software libre y comercial y criterios comunes para los grupos A y B.

Los guiones específicos de cada unidad permanecen dentro de su propia carpeta. La versión destinada a la web se mantiene en `.site-src/profesorado`.
