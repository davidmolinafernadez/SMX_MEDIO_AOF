# Protocolo para liberar la empresa modelo

El ejemplo NexoByte acompaña todo el curso, pero no debe sustituir el pensamiento del alumnado.

| Momento | Material visible |
|---|---|
| Inicio de unidad | Problema, cliente, criterios de calidad y un fragmento corto |
| Tras decisión propia | Tabla, captura o párrafo comparable |
| Tras primer borrador | Modelo público de la unidad y preguntas de contraste |
| Después de entregar | Producto completo liberable y análisis de errores frecuentes |

En Aules se enlaza la página `Empresa ejemplo · NexoByte` correspondiente. La carpeta `Docente_privado` nunca se adjunta ni se sube a GitHub.

La comparación se entrega como tres respuestas breves: **qué mantendría**, **qué cambiaría** y **por qué mi solución es adecuada para mi empresa**.
