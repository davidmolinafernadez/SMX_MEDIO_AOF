# Rúbrica base común

Para cada CA se redactan descriptores específicos, manteniendo cuatro niveles enteros. La calidad transversal limita el nivel alcanzable:

- **Adecuación:** responde al encargo y destinatario.
- **Técnica:** funciona y utiliza correctamente las herramientas.
- **Comunicación:** estructura, lenguaje y accesibilidad.
- **Proceso:** planificación, versiones, plazo y verificación.
- **Fuentes e IA:** uso declarado, crítico y seguro.

Preguntas de defensa: “¿Qué decisión tomaste y por qué?”, “¿Cómo modificarías X si cambiara Y?” y “Enséñame dónde se realiza esta función”.
