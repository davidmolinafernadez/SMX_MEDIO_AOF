# Lista de comprobación del puesto

## Antes

- [ ] Necesidad, usuario e inventario definidos
- [ ] Requisitos oficiales comprobados
- [ ] Licencia y uso profesional verificados
- [ ] Origen, versión y arquitectura confirmados

## Durante

- [ ] Opciones y componentes registrados
- [ ] Identidad e idiomas configurados
- [ ] Formato, recuperación y actualización configurados

## Después

- [ ] Crear, guardar, cerrar y reabrir
- [ ] Exportar a PDF y comprobar corrector
- [ ] Registrar incidencias y versión final
- [ ] Revisión entre iguales realizada; entrega y evidencias propias
