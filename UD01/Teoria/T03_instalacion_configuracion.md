# T03 · Instalar y configurar con método

```text
Necesidad → requisitos → origen seguro → instalación → configuración → verificación → mantenimiento → retirada
```

## Fases

1. **Necesidad:** usuario, tareas, intercambio de archivos, idiomas y restricciones.
2. **Requisitos:** sistema, arquitectura, CPU, RAM, disco, dependencias y permisos; diferenciar mínimo y recomendado.
3. **Origen seguro:** web oficial, tienda o repositorio; versión e idioma correctos; checksum si existe.
4. **Instalación consciente:** decidir típica/personalizada, componentes, ruta, asociaciones y accesos. En Linux, explicar el gestor de paquetes.
5. **Configuración empresarial:** identidad, idiomas, formato, recuperación, actualizaciones, privacidad y extensiones autorizadas.
6. **Aceptación:** abrir, crear, guardar, cerrar, recuperar, exportar a PDF y comprobar en otra suite.
7. **Mantenimiento/retirada:** registrar versiones y retirar mediante el mecanismo del sistema, conservando los datos necesarios.

Se demostrará el mismo objetivo en LibreOffice y Microsoft 365. Cambia la interfaz, no la competencia.
