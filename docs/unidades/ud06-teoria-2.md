# 2. Exportación, subtítulos y prueba

Contenedor (MP4) agrupa; códec (H.264/AAC) comprime. Resolución, fps, bitrate y audio determinan compatibilidad, peso y calidad.

## Perfil orientativo

MP4, H.264, 1080p, 25/30 fps, audio AAC y calidad suficiente para leer interfaz. Se parte de un perfil y se prueba; no se sube bitrate sin límite. El archivo se reproduce en otro equipo y se avanza a tres puntos.

## Subtítulos

La transcripción automática es borrador. Se corrigen nombres, puntuación, tiempos y longitud; se identifican sonidos relevantes. Se entregan incrustados o archivo SRT según plataforma, además de guía escrita equivalente.

## Prueba de usuario

Una persona de perfil objetivo ejecuta la tarea solo con el tutorial. Observador registra tiempo, pausas, errores y preguntas sin ayudar. Se corrigen al menos dos problemas y documenta antes/después.

## Práctica guiada

Exporta 720p y 1080p con ajustes razonables, compara lectura/peso, genera subtítulos y prueba en otro equipo. Completa: versión, duración, tamaño, códec, dispositivo y resultado.

!!! failure "No basta con que se reproduzca"
    Si el usuario no completa la tarea, el tutorial no cumple aunque tenga buena imagen.
