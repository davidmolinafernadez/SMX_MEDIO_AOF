# 2. Análisis, gráficos y automatización

Analizar es responder una pregunta, no decorar una hoja.

## Calidad y exploración

Se eliminan duplicados justificados, validan categorías, filtran valores anómalos y conservan datos originales. Ordenar solo una columna rompe registros; se selecciona toda la tabla.

## Tabla dinámica

Pregunta: «¿cuánto vendemos por mes y categoría?» Filas = categoría; columnas = mes; valores = suma de importe; filtro = canal. En Calc y Excel cambia el panel, no la lógica. Se actualiza al cambiar el origen.

## Elegir gráfico

- Barras: comparar categorías.
- Líneas: evolución temporal.
- Dispersión: relación entre dos variables.
- Circular: pocas partes de un total; se evita si dificulta comparar.

Título informativo, unidad, periodo, fuente y escala honesta. No usar 3D, veinte colores ni doble eje sin justificación.

## Automatización

El profesor graba una macro que actualiza/ordena una copia y prepara impresión. Se explica seguridad, alcance y diferencia Basic/VBA. Alternativamente se automatiza con herramientas nativas si una macro añade riesgo.

## Práctica guiada

Importa CSV, valida, filtra, crea tabla dinámica, elige un gráfico y construye tres KPI. Cambia tres registros y actualiza. Define área de impresión, repite encabezados y exporta PDF.

**Control:** cada KPI debe responder una pregunta y permitir rastrear el dato. [Panel NexoByte](../ejemplo/ud03.md).
