# UD01 · Suites ofimáticas — Preparamos los puestos de trabajo

**Duración de referencia:** 8 sesiones, 14 horas. **RA:** RA1 completo.

## Encargo

Los equipos están vacíos. Cada técnico debe seleccionar, instalar, configurar, actualizar, verificar y documentar el software necesario, respetando requisitos y licencias.

## Teoría y microtalleres

**Ruta guiada:** [0. Entorno de trabajo](ud01-teoria-0.md) → [1. Software y licencias](ud01-teoria-1.md) → [2. Instalación y configuración](ud01-teoria-2.md) → [3. Documentar y resolver](ud01-teoria-3.md).

1. **Entorno de trabajo:** `home`, rutas, Dolphin, extensiones, árbol `Empresa/UDx`, nombres/versiones y rutina de mecanografía de 5-10 minutos.
2. **Software y licencias:** propietario, libre, permisivo/copyleft, freeware, prueba, adware y uso comercial. Toda afirmación de IA se verifica en la fuente oficial.
3. **Instalación profesional:** requisitos → origen oficial → versión/arquitectura → instalación → identidad/idiomas/formatos/autoguardado → prueba → actualización → desinstalación limpia.
4. **Incidencias:** síntoma, reproducción, aislamiento, búsqueda, una prueba cada vez, causa, solución y evidencia.

## A1 · Los ordenadores han llegado

- Seleccionar suite y dos aplicaciones adicionales, justificando necesidad y licencia comercial.
- Instalar y configurar identidad, correctores, formato acordado y autoguardado cada 10 minutos.
- Actualizar, verificar con documento de prueba y desinstalar limpiamente un componente.
- Entregar informe reproducible y registro de incidencias; el equipo se comprueba en clase.

**Pesos CA:** a 8%, b 10%, c 15%, d 12%, e 10%, f 7%, g 8%, h 15%, i 15%.

## A2 · «Instálalo pirata, que es gratis»

Informe de una página para gerencia: riesgos legales, económicos, de seguridad y de cliente; alternativas legales para Office, Photoshop y AutoCAD; licencias/fuentes oficiales; ahorro estimado; prompt usado y corrección o verificación de la IA. Pitch de 2 minutos.
