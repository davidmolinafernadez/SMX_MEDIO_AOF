# Cómo trabajaremos

Cada unidad sigue un ciclo profesional común:

1. **Briefing:** el cliente presenta una necesidad.
2. **Microtalleres:** practicamos solo las herramientas necesarias.
3. **Producción:** elaboramos el encargo individualmente o en equipo.
4. **Control de calidad:** lista de comprobación y revisión entre iguales.
5. **Entrega:** archivo final, evidencias y registro de decisiones.
6. **Defensa breve:** preguntas individuales para comprobar la autoría y comprensión.
7. **Retrospectiva:** qué conservar, corregir o automatizar.

## Portafolio

Cada alumno mantiene `AOF_Apellido_Nombre/` con una carpeta por unidad y un índice de evidencias. Los archivos deben llevar versión y fecha, nunca nombres como `final_final2`.

## Uso responsable de IA

Se puede utilizar cuando el encargo lo permita, declarando finalidad, prompt, resultado aprovechado y comprobaciones realizadas. La persona que entrega responde de la exactitud, privacidad y calidad del producto.
