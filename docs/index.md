# Bienvenido/a a la empresa

Este curso no consiste en aprender botones aislados. Desde el primer día formarás parte de una empresa de servicios digitales y resolverás encargos para clientes simulados.

Cada encargo deja un producto útil para el siguiente: la identidad aparece en los documentos, los datos alimentan las presentaciones y todo acaba reunido en un portafolio profesional.

## Tu evolución

1. **Técnico/a júnior:** sigues procedimientos y documentas lo realizado.
2. **Técnico/a:** eliges herramientas y justificas decisiones.
3. **Responsable de proyecto:** integras productos y los defiendes ante el cliente.

## Regla de calidad

> Antes de entregar, pregúntate: ¿un cliente aceptaría y usaría este trabajo?

Los grupos A y B siguen el mismo recorrido, calendario de hitos y criterios de evaluación.
