# Guía docente · UD1

- **Sesiones clave:** inventario; licencias; instalación; configuración; prueba; documentación.
- **Práctica mínima:** instalar o configurar una aplicación permitida, verificarla y revertir cambios.
- **Datos comunes A/B:** mismo catálogo de necesidades y tabla de requisitos.
- **Errores preparados:** versión incompatible, formato no asociado, ruta incorrecta y actualización pendiente.
- **Entregable:** `UD1_Apellido_Nombre_Informe.pdf` más evidencias.
- **Recuperación:** repetir la prueba de aceptación sobre otra aplicación.
