# A2 · Manual técnico para el cliente

Crear, con la plantilla A1, un manual con introducción, instalación, configuración y resolución de problemas. Importar notas DOCX, generar índice automático, insertar referencia cruzada, grabar una macro, realizar revisión con control de cambios y comprobar el PDF final.

## Entrega

- ODT limpio, sin cambios pendientes.
- PDF con índice y enlaces comprobados.
- Nota que explica la macro.

Pesos: RA2.d 30%, RA2.e 30%, RA2.f 40%.
