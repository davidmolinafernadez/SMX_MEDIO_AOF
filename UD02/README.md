# UD02 · Procesadores de texto — Identidad documental de la empresa

Empieza por `00_CONTENIDO_COMPLETO.md`. La unidad se distribuye así:

- `Teoria/`: seis bloques con explicaciones desde cero, ejemplos resueltos y talleres: formato, estilos, documento complejo, índices/PDF, gestión y Markdown/IA/web.
- `Actividades/`: retos y cinco encargos con fases guiadas, materiales de partida, comprobaciones y modelos para completar.
- `Evaluacion/`: correspondencia con RA2 y pesos.
- `Recursos/`: archivos que debe preparar el profesorado.
- `GUIA_DOCENTE.md`: orientación de sesiones y coordinación A/B.

Para preparar la web documental, empieza por [Markdown, IA y web](Teoria/06_markdown_ia_web.md). Incluye sintaxis, prompts comentados, revisión de respuestas y construcción de una web local. Después sigue [ACT-2.4](Actividades/A4_revision_cruzada.md).
